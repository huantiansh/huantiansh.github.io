## 为什么要量化

「这个 AMV 好有感觉」通常没法直接执行。能执行的是：

- 镜头平均多长、中位多长；
- 哪些段落是快切、哪些段落是长呼吸；
- 前半和后半的亮度/饱和度差多少；
- 转场用什么手法、出现在什么时间点。

这些都可以从参考片里量出来。

## 镜头切点

用 ffmpeg 的 scene 检测拿切点：

```bash
ffmpeg -v info -ss 157 -t 110 -i reference.mp4 \
  -vf "select='gt(scene,0.25)',showinfo" \
  -an -f null - 2> scene.log
```

把 `pts_time` 抽出来，排序后算相邻差值，就得到镜头长度列表。

本片参考的是一支同曲 ED 字幕视频，2:37–结束的统计：

| 指标 | 数值 |
|------|------|
| 镜头数 / 时长 | 78 个 / 110 秒 |
| 平均镜头 | 1.41 秒 |
| 中位镜头 | 1.10 秒 |
| 最短 / 最长 | 0.03 秒 / 5.90 秒 |

结论不是「要剪得快」，而是：**快切为主，但保留 3–5.9 秒的长镜头做呼吸**。

## 色调分段

用 Python + Pillow 对每秒抽帧算平均亮度、饱和度、对比度：

```python
import numpy as np
from PIL import Image

im = np.asarray(Image.open("frame.jpg").convert("RGB"), dtype=np.float32)
lum = np.mean(0.299 * im[:, :, 0] + 0.587 * im[:, :, 1] + 0.114 * im[:, :, 2])
sat = np.mean(np.max(im, axis=2) - np.min(im, axis=2))
```

参考片的分段结果：

| 段落 | 平均亮度 | 平均饱和度 | 判断 |
|------|----------|------------|------|
| 2:37–3:00 | 70.7 | 13.5 | 暗调 / 近黑白 |
| 3:00–3:38 | 67.5 | 13.1 | 暗调 / 近黑白 |
| 3:38–4:00 | 71.8 | 24.3 | 饱和度上升，颜色回来 |
| 4:00–结束 | 44.3 | 24.0 | 变暗，尾奏黑场 |

一眼能看出的分界点：**3:38**。前半饱和度只有 13 左右，后半升到 24 左右。

## 镜头语言

拆完联系表后，把镜头按类型标记：

- **人物特写**：眼睛、侧脸、剪影、发丝；
- **动作**：走路、回头、伸手、拥抱；
- **空镜**：桌面、台灯、腿部、走廊、天空；
- **特殊效果**：黑场字卡、画中画/黑框、叠化、双重曝光、亮闪。

参考片前半（2:37–3:38）主要是「眼睛/侧脸/空镜 + 低饱和暗调」；3:38 后镜头变长，转向「人和空间的关系」。

## 从参考到参数

不要照搬画面，而是把语法翻译成自己的参数：

| 参考片做法 | 可执行参数 |
|------------|------------|
| 前半低饱和、暗调 | `eq=saturation=0.10:brightness=-0.08:contrast=1.20:gamma=0.90` |
| 3:38 色彩回来 | 饱和度用 1.5–2 秒从 0.10 渐变到 1.25 |
| 快切 + 长镜头呼吸 | 前半 0.8–1.5 秒一切，偶尔 3–5 秒 |
| 眼部/侧脸特写 | 选镜优先眼睛、侧脸、手、水面、空镜 |
| 叠化/双重曝光 | `blend=all_mode=screen`，只做 0.8 秒短转场 |
| 结尾黑场 | 尾奏留 3–5 秒渐黑 |

## 一个提醒

视觉模型可以帮你快速看联系表，但它对「这是谁」「有没有文字」经常判断错。**关键镜头一定要自己看**，至少抽查单帧：

- 有没有字幕、海报、制作名单；
- 人物是不是主角；
- 画面里有没有会干扰歌词的文字。

参考片拆解的价值在于「语法」，不在于「复制」。下一篇讲我们怎么把这些语法落到剪辑上。

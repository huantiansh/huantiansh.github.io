## 第一版的失败

第一版严格按分镜表执行：一句歌词配一个镜头。

结果很糟：

- 每 3 秒换一集、换一个场景；
- 画面之间没有关系，像幻灯片；
- 同一个场景被反复用，观众一眼能看出来；
- 明明素材占比很高，却没有剧情感。

问题不在素材量，在**剪辑语言**。

## 先搭连续场景

第二版改成以「剧情段落」为单位：

| 时间 | 剧情段落 | 来源 |
|------|----------|------|
| 0:00–0:43 | 体育馆相遇 → 约定 → 回家 | EP1 |
| 0:43–1:17 | 门前 → 薄扉 → 否认 | EP2 |
| 1:17–1:30 | 水滴 → 圣诞邀约 | EP4 / EP5 |
| 1:30–2:11 | 圣诞约会 | EP6 |
| 2:11–2:37 | 情人节 → 2 月 14 日早晨 | EP7–EP9 |
| 2:37–3:13 | 眼泪 → 牵手 → 拥抱 | EP11 |
| 3:13–4:06 | 梦境 → 高潮 → 快要碰到 | NCED / EP11 / EP12 |

每个段落内部，按原片的镜头顺序走，使用原片的切点。这样人物、场景、时间都是连续的，观众能跟得上。

## 再按歌词补意象

连续场景解决了「剧情连贯」，但没有解决「歌词对不上」。

所以第二层是**歌词意象插入**：

- 「思い出」→ 水；
- 「約束」→ 回家路；
- 「書きかけの言葉 / 雫」→ 水面；
- 「三日月」→ 水面倒影；
- 「変わらぬ瞳」→ 眼睛特写；
- 「少しだけ」→ 手；
- 「深い水の底」→ 水下；
- 「波に波に」→ 水波。

插入镜头不一定要来自当前集。只要它和歌词的意思对得上，并且和前后镜头有**匹配关系**，就可以用。

## 匹配剪辑

把两个镜头接在一起，要让观众感觉「有关系」，常用四种：

| 类型 | 例子 |
|------|------|
| 动作匹配 | 上一镜伸手，下一镜手已经握住 |
| 视线匹配 | 上一镜人物看向画外，下一镜切到被看的人/物 |
| 形状匹配 | 圆形画框 → 圆形光斑；水面 → 眼睛高光 |
| 色彩/光线匹配 | 冷蓝水面 → 冷蓝走廊；暖色灯光 → 暖色拥抱 |

硬切不可怕，可怕的是两个镜头之间没有任何关系。

## 不要反复用同一段

「同一场景」和「同一镜头」是两回事。

可以用同一场戏，但要拆成不同景别、不同时刻：

- 全景交代空间；
- 中景看人物关系；
- 特写看情绪；
- 手/眼睛/背影做节奏点。

每个镜头只用一次。这样既保留了连续感，又有新鲜感。

## 配角可以出现，但别让配角占主线

配角镜头可以做环境、反应、群像，但情绪核心要留给主角。

判断方法很简单：把这一镜静音看一遍——**如果它是配角的大特写，而歌词正在讲主角的内心，就换掉**。

## 运动只用来衔接

一个反直觉的经验：**静态镜头不要硬加推拉**。

如果这一镜是静止的，下一镜是运动的，可以在中间加一个转场（叠化、双曝、亮闪），让运动「接」过去；而不是给静态镜头加一个假推拉。

本片的原则：

- 静止镜头保持静止；
- 运动来自原片（走路、发丝、水波、人物动作）；
- 转场只在需要衔接时使用；
- 不做无意义的缩放。

## 2 秒覆盖插入

为了让 12 集和 OP/ED 都有出场，可以在剧情段里替换等长的 2 秒镜头：

- 用 EP3/EP10 的角色镜头补覆盖；
- 用 NCOP02 的动画 OP 镜头补 OP 存在感；
- 每个插入只替换 2 秒，总时长不变；
- 插入位置选在歌词句子的边界，避免在动作中间硬切。

这样既不影响主线，又能让素材库更丰富。

## 小结

- 先把剧情剪顺，再插歌词意象；
- 用匹配剪辑把不同镜头接起来；
- 同一场景可以重复，同一镜头不要重复；
- 配角做环境，主角做情绪；
- 静态镜头不硬加运动，转场负责衔接。

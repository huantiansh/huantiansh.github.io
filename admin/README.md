# 本地后台

只在本机运行的 Hugo 博客管理后台。直接读写项目文件，不部署到 GitHub Pages。

## 启动

```bash
npm run admin
```

打开 http://127.0.0.1:4321 。

依赖只有项目已有的 `sharp` 和 Node 内置模块，不需要额外安装。

## 功能

- 站点设置：站点名、副标题、描述、主题色、文章字号、作者信息、默认封面、页脚、favicon/头像裁剪。
- 头图中心：首页 Hero 图片/视频、关于/归档/分类/标签/友链/追番/留言页面的头图、文章默认封面。
- 文章：列表、新建、编辑标题/描述/日期/分类/标签/作者/封面/正文、置顶/草稿、删除。
- 页面：关于、友链、追番、留言的标题/头图/正文；归档/分类/标签主要改头图。
- 媒体库：上传图片/视频、预览、复制路径、删除；图片可裁剪、可直接设为头像。
- 外观与组件：Hero 文案、公告栏、社交链接、音乐、Live2D、Utterances 评论配置。
- 预览与发布：Hugo 构建、启动/停止本地预览、Git 状态、提交、推送。

## 安全

- 服务只绑定 `127.0.0.1`，没有登录系统，不要把它暴露到公网或局域网。
- 上传只写入 `static/uploads` 或 `static/hero`；覆盖前会备份到 `admin/backups/`（已忽略，不进库）。
- `git push` 使用本机已有的 Git 凭据；如果代理没开，推送会失败，后台会显示输出。

## 注意

- 后台是功能型界面，不做美化。
- 文章/页面正文是 Markdown，没有富文本编辑器。
- 分类/标签的**单个词条页**没有单独头图，只有分类/标签总览页的头图。
